# 기경대 대여사업 웹앱 (사용자용 데모)

앱스토어 없이 링크로 여는 웹앱(PWA)입니다. 데이터는 목업이며, 각 사용자의 브라우저에만 저장됩니다.

## 파일
- index.html — 화면과 동작 전부
- sw.js — 오프라인 캐시, 알림 처리
- manifest.webmanifest, icon-192.png, icon-512.png — 홈 화면 추가용

## 가장 쉬운 배포: Netlify Drop (1분)
1. https://app.netlify.com/drop 접속
2. 이 폴더(rental-app)를 통째로 끌어다 놓기
3. 나오는 https 주소를 휴대폰으로 열기

## GitHub Pages로 배포
1. 새 저장소를 만들고 이 폴더의 파일 5개를 올림
2. Settings → Pages → Branch: main / root → Save
3. 1~2분 뒤 https://아이디.github.io/저장소이름/ 으로 접속

※ 알림과 홈 화면 추가는 https 주소에서만 동작합니다. 파일을 더블클릭해서 열면 화면은 보이지만 알림은 안 됩니다.

## 시연 순서
1. 홈: 기경대/ITM 전환, 무궁관/프론티어관 전환
2. 돗자리(0개) 누르기 → 다른 건물에 남은 수량 안내 후 자동 이동
3. 우산 누르기 → 학번·이름 입력 → 대여하기
4. 내 대여: 반납 예정일, 반납했어요 → 재고 +1
5. QR 대여 → '사물함에 붙일 QR 보기' → 휴대폰 카메라로 찍으면 그 사물함 화면이 열림
6. 종 아이콘 → 반납 알림 켜기 (아이폰은 홈 화면에 추가한 뒤)
7. 내 대여 맨 아래 '데모 데이터 처음으로'로 초기화

## 데모의 한계 (기획안 2단계 이후 과제)
- 재고는 기기마다 따로 저장됩니다. 실제 공유 재고는 서버(예: Firebase)가 필요합니다.
- 알림은 앱을 열 때 반납 임박 물품을 알려주는 방식입니다. 앱을 닫아도 오는 예약 푸시는 서버 연동이 필요합니다(sw.js에 받는 자리는 준비됨).
